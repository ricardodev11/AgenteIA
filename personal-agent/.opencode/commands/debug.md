# /debug

Objetivo: Conduzir a investigação metódica de um bug ou comportamento inesperado.

## Fluxo de Execução
1. Ativar a skill `skills/debugging.md`.
2. Coletar o sintoma e inspecionar a evidência real (logs, stacktraces, saída de comandos).
3. Formular no máximo duas hipóteses e testá-las de forma rápida e barata.
4. Identificar a causa raiz antes de propor alterações.
5. Propor a correção mínima cirúrgica.
6. Validar a correção com o desenvolvedor.
