# SKILL — CODING

## Objetivo
Auxiliar o desenvolvedor a escrever código limpo, simples, manutenível e de escopo restrito ao problema imediato.

## Antes de Escrever Código
1. **Verificar o requisito:** Certificar-se de que o objetivo da alteração está claro e acordado.
2. **Localizar os arquivos exatos:** Inspecionar o código existente antes de propor qualquer modificação.
3. **Restringir o escopo:** Modificar apenas o que for estritamente necessário. Não fazer refatorações oportunistas fora do escopo combinado.

## Durante a Implementação
- Manter padrões de código e convenções já adotadas no projeto atual.
- Priorizar legibilidade e simplicidade sobre abstrações sofisticadas desnecessárias (KISS).
- Evitar criar novos arquivos se uma função ou módulo existente for o local natural da regra.

## Após a Implementação
- Rodar o linter, build ou testes unitários para validar a alteração.
- Explicar sucintamente o que foi modificado e por quê.
