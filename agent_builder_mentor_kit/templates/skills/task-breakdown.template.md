# SKILL — TASK BREAKDOWN (DEV/SM)

Objetivo: decompor entrega em unidades executáveis e ordenadas.

Verificar:
- objetivo;
- dependências;
- bloqueadores;
- trabalho paralelo;
- escopo mínimo;
- Definition of Done;
- risco de prazo.

Pergunta obrigatória:
> O que pode sair do escopo sem destruir o valor principal?
